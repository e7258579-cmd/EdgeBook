# הגדרת ההתראה ב-TradingView (V01)

מטרה: ש-TradingView ישלח ל-Firebase הודעה בכל כניסה ויציאה של האסטרטגיה. **הכול ב-DRY_RUN בהתחלה:** גם אם ההודעות מגיעות, שום פקודה לא נשלחת ל-TradeZero עד שמשנים `dryRun` ל-`false` ב-Firestore.

## לפני שמתחילים

- הבק-אנד פרוס ב-Firebase (`firebase deploy --only functions`), ויש לך את כתובת הפונקציה `tzWebhook` (שונה מהכתובת של `tzWebhookTest`).
- אתה יודע את הערך של `WEBHOOK_SECRET` (אותה סיסמה שהגדרת ב-Firebase).

## שלב 1: לבדוק את ההודעות על הגרף, בלי לשלוח כלום

1. בהגדרות האסטרטגיה, בקבוצה **Webhook**, סמן **"Show each webhook message as a chart label"**.
2. על הגרף יופיעו תוויות קטנות ("entry" ו-"exit") בכל עסקה, גם בהיסטוריה.
3. העבר את העכבר על תווית. אמור להופיע JSON כזה (הסיסמה מוסתרת):
   ```
   {"secret":"***","v":1,"event":"entry","symbol":"WHLR","barTime":1759745340000,"tf":"1","strategy":"V05","session":"pre","price":4.06,"stop":3.78,"trigger":4.06,"mode":"stopbuy","qtyHint":25}
   ```
4. בדוק: המספרים סבירים, אין `NaN`, `price` מעל `stop`, וכל מספר כתוב עם ספרה לפני הנקודה (`0.5`, לא `.5`).
5. אם משהו נראה שגוי, שלח לי צילום מסך של התיאור.

## שלב 2: להפעיל את השליחה

1. בקבוצה **Webhook** סמן **"Send webhook alerts"** והכנס את הסיסמה בשדה **"Webhook secret"**.
2. **אל תפרסם ואל תשתף את הסקריפט עם הסיסמה בתוכו.** הסיסמה היא חלק מכל הודעה.

## שלב 3: ליצור את ההתראה

1. על הגרף (סמל אחד = גרף אחד = התראה אחת), לחץ **Alert** (השעון).
2. **Condition:** בחר את האסטרטגיה "EdgeBook Strategy", ובתפריט שלידה בחר **"alert() function calls only"** (ולא "order fills").
3. **Notifications:** סמן **Webhook URL** והדבק את כתובת `tzWebhook`.
4. את תיבת ה-**Message** אפשר להשאיר כמו שהיא: היא לא בשימוש, ההודעה מגיעה מהקוד.
5. שמור.

## שלב 4: לבדוק ש-ההודעות מגיעות

1. חכה לעסקה בזמן אמת (ההתראה לא נשלחת על היסטוריה).
2. ב-Firebase Console, באוסף `signals`, אמור להופיע מסמך עם `status` של `accepted` (או `rejected`/`ignored` עם סיבה). ב-DRY_RUN תראה גם `dryRun: true`.
3. באוסף `orders` אמורה להופיע הפקודה שהייתה נשלחת (`Buy`/`Sell`, Limit, המחיר, הכמות).

## הערות

- התראה אחת לכל גרף. אם האסטרטגיה רצה על כמה מניות, צריך גרף והתראה לכל אחת.
- ב-TradingView יש מגבלות על מספר ההתראות לפי התוכנית.
- כדי להפסיק לשלוח: כבה את ההתראה, או את "Send webhook alerts".
- הבק-אנד ב-DRY_RUN נבדק רק מול הבדיקות היחידה. אם משהו מהתהליך הזה לא עובד, שלח לי את המסך או הלוג.
